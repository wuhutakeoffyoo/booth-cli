# benchmarks —— 中文泛称搜索盲测记录

本目录存放「100 个 VRC 改模常见物件/功能/素材中文泛称词」的盲测方法、词表、探针脚本与各轮结果，用于跟踪中文搜索链路的查询级命中率。

## 方法

- **词表**：`words100.json` —— 100 个 VRC 玩家改模常见的小物件/功能/素材中文泛称词（铃铛、猫耳、项圈、拍头、女仆装、渐变发色、法线贴图……），覆盖配件/功能/服装/发型/素材五类。
- **执行**：`run100_probe.py` 逐词调用 bot 文本链路的完整管线（AI 方案规划 → 分词合并搜索 → 结果评估 → 二轮重搜），每词取 Top6。支持断点续跑与双进程并行。
- **判定口径**：一个词的前 6 条结果中 **≥4 条与词义明确相关** 即记命中（子串沾边但品类不符计为不相关）。
- **环境**：本地开发机（国内网络出口）+ 用户自有 AI API 配置；对 booth.pm 的请求遵守内置限速。

## 结果轮次（详见 report-2026-10-01-generic-words.md）

| 轮次 | 查询级命中 | 说明 |
|---|---|---|
| R0 基线 | 87/100 | 13 词失败，暴露方案方差/评估宽松/CJK 单字词 bug |
| R1 | 96/100 | 严格评估（hits≥3）+ 保守 retry + 同义词 v1 |
| R2 | 96/100 | 产量探针重排同义词 + 单字读音规则 + 禁上位词 + 深度 15 |
| R3 | 94/100 | 方差词轮换翻出（蝴蝶结/脸红/哥特萝莉） |
| 终态 | 16 词钉入同义词表并逐词 5-6/6 复验；三轮并集覆盖 98/100 | 已知结构性受限词：短裙、发型切换 |
| **复测（10-02）** | **99/100** | 突破改造（CLI 1.5.1 + Bot 0.3.1）后全量复测，唯一失败：发型切换（结构性）；详见 report-2026-10-02-post-breakthrough.md |
| **随机目标（10-02）** | 87/100 严格口径（供给覆盖口径 91-92） | 100 个随机抽取目标（含专有名/小众品类/功能描述），分布本质更难；详见 report-2026-10-02-random-targets.md |

## 文件

## 复跑

```bash
cd <bot 仓库> && .venv/Scripts/python.exe <本目录>/run100_probe.py <words100.json> <输出目录> [起始] [结束]
```

注意：
- **防风控约定**：`RUN_PROFILE=benchmark`（默认禁止 AI 调用，除非显式 `BENCHMARK_ALLOW_AI=true`）；
  同机子进程经 `BOOTH_REQUEST_BUDGET_DB` 共享请求预算（跨进程 ≥1 秒准入 + 429 冷却），
  并行进程数建议 ≤2；大规模评测使用独立账号/配额，避免与生产共享 AI 限额。
- 评测前递增查询缓存语义版本（CACHE_VERSION）以免命中旧结果。
- 每查询有出站上限（首轮 12 / 二轮 18）与总时限（默认 180 秒），超限明确报错而非放宽。
